reChess API

JSON API of the reChess shop. Request bodies are generated from the zod schemas of the routes; response shapes are described in words. Base path: /api. Machine-readable: openapi.json.

Public

GET /health

Liveness check

  • 200 – Service status
  • 400 – Validation error: { error, details }

GET /products

Products with colours, prices and photos

  • 200 – { products }
  • 400 – Validation error: { error, details }

GET /products/{id}/price

Current price of a product

  • id (path) – Product id
  • 200 – { product_id, price }; 404 when unknown
  • 400 – Validation error: { error, details }

GET /pages

Published pages with blocks

  • 200 – { pages }
  • 400 – Validation error: { error, details }

GET /pages/{slug}

One published page

  • slug (path) – Page slug
  • 200 – The page; 404 when unknown
  • 400 – Validation error: { error, details }

GET /settings

Public site settings

  • 200 – Settings by code
  • 400 – Validation error: { error, details }

GET /shops

Shops

  • 200 – { shops }
  • 400 – Validation error: { error, details }

GET /index-photos

Photos of the home page

  • 200 – { photos }
  • 400 – Validation error: { error, details }

GET /seller

Seller details

  • 200 – { seller }
  • 400 – Validation error: { error, details }

GET /site

Everything the site build needs in one response

  • 200 – Site content
  • 400 – Validation error: { error, details }

Shop

GET /cart

Cart of the visitor

Auth: visitor cookie (optional)

  • 200 – Cart view: items, count, total
  • 400 – Validation error: { error, details }

POST /cart/items

Add a product to the cart

Auth: visitor cookie (optional)

Body: AddCartItemBody

  • 200 – Updated cart view; sets the visitor cookie on first use
  • 400 – Validation error: { error, details }

PATCH /cart/items/{itemId}

Change the quantity of a cart line (0 removes it)

Auth: visitor cookie (optional)

  • itemId (path) – Product id

Body: CartQuantityBody

  • 200 – Updated cart view
  • 400 – Validation error: { error, details }

DELETE /cart/items/{itemId}

Remove a cart line

Auth: visitor cookie (optional)

  • itemId (path) – Product id
  • 200 – Updated cart view
  • 400 – Validation error: { error, details }

GET /checkout/prefill

Checkout data from the previous order

Auth: visitor cookie (optional)

  • 200 – { contact } (null when unknown)
  • 400 – Validation error: { error, details }

GET /checkout/delivery

Delivery options for the cart and a city

Auth: visitor cookie (optional)

  • city (query) – City name
  • 200 – Weight, door and pickup costs
  • 400 – Validation error: { error, details }

POST /orders

Place an order from the cart

Auth: visitor cookie (optional)

Body: OrderBody

  • 201 – { order } with its payment
  • 400 – Validation error: { error, details }

GET /orders/{number}

An order of this visitor

Auth: visitor cookie (optional)

  • number (path) – Order number
  • 200 – { order }; 404 for someone else’s order
  • 400 – Validation error: { error, details }

GET /orders/{number}/payment

Payment state of an order

Auth: visitor cookie (optional)

  • number (path) – Order number
  • 200 – { payment }
  • 400 – Validation error: { error, details }

POST /orders/{number}/payment

Retry the payment of an order

Auth: visitor cookie (optional)

  • number (path) – Order number
  • 200 – { payment }
  • 400 – Validation error: { error, details }

POST /payments/{provider}/notify

Payment notification from a provider (the stub page sends it too)

  • provider (path) – Provider code, e.g. stub

Body: StubNotificationBody

  • 200 – { state, changed }; repeats are harmless
  • 400 – Validation error: { error, details }

CMS uploads

Upload an image (multipart field file, up to 10 MB; jpg, png, webp, avif)

Requires one of the permissions: references, pages, seo, settings.

Auth: CMS session cookie

  • 200 – { photo } – stored file name
  • 400 – Validation error: { error, details }

  • 403 – Missing permission

CMS tables

GET /cms/tables/{name}

List rows (search, sort, page)

Auth: CMS session cookie

  • name (path) – Table name: color, product, delivery_tariff, item, item_photo, index_photo, shops, shop_photo, seller, order_state, price, seo, page, page_block, setting, user, role, client, cart, order
  • q (query) – Search text
  • page (query) – Page number
  • sort (query) – Sort column
  • 200 – Rows and the total count
  • 400 – Validation error: { error, details }
  • 401 – No valid session
  • 403 – Missing permission

POST /cms/tables/{name}

Create a row; the body is validated by the schema Cms_<name>

Auth: CMS session cookie

  • name (path) – Table name: color, product, delivery_tariff, item, item_photo, index_photo, shops, shop_photo, seller, order_state, price, seo, page, page_block, setting, user, role, client, cart, order

Body: one of the Cms_* schemas below, chosen by the table name

  • 201 – { row }
  • 400 – Validation error: { error, details }
  • 401 – No valid session
  • 403 – Missing permission
